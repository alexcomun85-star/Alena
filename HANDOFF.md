## 4. Сайт: устройство

Статический сайт без сборщика: HTML + один CSS + ванильный JS. Все пользовательские данные — только в `localStorage` браузера, на сервер ничего не уходит.

**Публикация:** любой push в `main` → GitHub Actions (`.github/workflows/pages.yml`) публикует сайт; также ежедневно в 07:00 МСК `scripts/update_data.py` обновляет `data/*.json` (новости ScienceDaily/BJSM с переводом через Яндекс Переводчик — секрет `YC_API_KEY`; посты канала; #вопрос/#разбор; #рецепт).

**Как вносить правки:**
1. `git clone https://github.com/alexcomun85-star/Alena` (нужны права на запись для push).
2. Править файлы. При изменении CSS/JS — поднять `?v=...` в подключениях на всех страницах (кеш). При заметных изменениях — поднять `VERSION` в `sw.js` (сейчас `alenafit-v9`).
3. Меню общее для всех страниц: менять только список в `scripts/build_nav.py` и запускать его, он переписывает блок между `<!-- nav:start -->` и `<!-- nav:end -->`.
4. Проверка: `python3 -m http.server 8766 &` и `python3 tests/regression.py` (Python Playwright + Chromium). Базовый набор — `tests/regression.py`, проверки аудита и Fold — `tests/audit_regression.py`; оба набора должны пройти.
5. Коммит и push в `main`.

**Страницы:** index, trener, pitanie, golod, recepty, korzina, odezhda, inventar, gadzhety, blizost (18+), nauka, testy, servisy (тренировка дня, таймер, тарелка, трекер, дневник по циклу), progress (журнал), kalorii, novosti, vopros, zal, vozvrat (план возвращения), offline, 404; `cal/*.ics`.

## 5. Последняя доработка: учёт женского цикла (27.10.2026)

Позиция, на которой всё построено: в среднем фаза цикла не влияет на силу и прогресс (McNulty et al., Sports Medicine, 2020 — 78 исследований, лишь тривиальное снижение в ранней фолликулярной фазе; Colenso-Semple et al., Frontiers in Sports and Active Living, 2023 — влияния не найдено). Поэтому **план меняется только по самочувствию**, а цикл даёт подсказки и личную картину. Аппетит: во второй половине цикла едят в среднем ≈168 ккал/день больше (Tucker et al., Nutrition Reviews, 2025); обмен в покое +≈30–120 ккал, 3–5 % (Hurtová et al., Frontiers in Physiology, 2026; Benton et al., PLoS One, 2020).

Реализовано:
- `js/cycle.js`: настройки `cycle_settings_v1` (`on` — по умолчанию false; `mode` regular/irregular/hormonal; `len` 21–45; `per` 2–10), дата начала `cycle_start_v1`. Функции `Cycle.dayOn`, `phase` (men / fol / lut — последние 14 дней / late / other), `windows` (прогноз месячных), `mount` (панель в любом `<div data-cycle-panel>`), `foodHint`, `trainHint`. Красные флаги «к гинекологу» в панели.
- Журнал: необязательные поля `cd` (день цикла 1–60) и `fe` (1 легко / 2 нормально / 3 тяжело) у силовых, `cd` у замеров; блок «Цикл и результаты» (сравнение с медианой упражнения за ±21 день, выводы от 12 записей за 2 цикла, порог ±3 %); вес к тому же дню прошлого цикла; данные цикла в PDF — только по галочке.
- Тренировка дня: «Самочувствие сегодня» → облегчённый вариант; при боли кор заменён на «кошку-корову» + совет к гинекологу.
- План возвращения: совет про тяжёлые дни; прогноз месячных на 4 недели при регулярном цикле.
- Калории: подсказка по дате, цифры не меняются. Тексты: `golod.html#pered-mesyachnymi`, `nauka.html#tsikl-eda`.
- Дневник самочувствия (`servisy.html#dnevnik`, ключ `cycle_diary_v1`) теперь берёт день из общих настроек.
