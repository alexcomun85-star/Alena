## Афита: переработка подбора и мобильного интерфейса, 29.10.2026

Причины: исходный подбор искал подстроку только в шести карточках сайта; фраза голосом без запятых не разбиралась. Несколько рядов кнопок и повторный заголовок отнимали мобильный экран. Подбор занятий открывал системные select.

Новый `js/recipe-engine.js` — локальный распознаватель русских названий продуктов и форм слов, 37 шаблонов приготовления, раздельные результаты с полным составом и с недостающими продуктами. У запроса без продуктов есть быстрые наборы. Неизвестные названия явно показаны, произвольные блюда не выдумываются. Поддерживаются исключения из состава. Это ограниченная, проверяемая библиотека, не универсальная генерация рецептов; количества и калорийность блюд не рассчитываются. Базовый подбор не вызывает модель и не отправляет продукты в сеть.

Интерфейс: одна компактная строка инструментов, при переключении возвращается начало экрана, сохраняются текущие поля сессии, результаты выдаются после явной кнопки. Формат выбирается радиокнопками. Результаты и рецепты можно сохранить в итог без дублей, удалить отдельно и выгрузить PDF. Для неизвестного продукта есть ручной расчёт по этикетке, каталог марок загружается один раз за сессию. Голосовой ввод зависит от сервиса браузера. Личные черновики не сохраняются в localStorage. Окно и основной чат остаются отдельными iframe, авторизация сервера сохранена.

Прототип нового сценария подготовлен в MagicPath (проект 466654561000640512, компонент 466654609834938368). Исходные снимки с телефона использованы для разбора и сравнения. Логика защищена `tests/recipe_engine.test.cjs`; браузерный набор `tests/assistant_actions.py` проверяет конкретную жалобу, недостающие продукты, пустой набор, варианты занятий без select, итог, PDF и переключение вкладок. Офферы не менялись. Календарь, автоматическая отправка заявок и вызов действий из серверного диалога по-прежнему требуют отдельной интеграции.

## Автоматические открытые источники в Афите, 30.10.2026

`js/online-data.js` подключает существующий сервер AlenaFit API. Если нет полного локального рецепта либо остались неизвестные продукты, после кнопки подбора выполняется поиск по русскоязычным рецептам Викиучебника. Состав, первые шаги, источник и авторство показываются в «Действиях», рецепт сохраняется в итог с указанием источника. Рецепты с известными исключёнными продуктами отфильтровываются; полнота состава и следы аллергенов не гарантируются. Никакой автоматической генерации или копирования вопроса в чат нет.

Если в локальной базе нет продукта, после паузы ввода запускается существующий поиск perek.us, с резервом Open Food Facts на сервере. Расчёты выполняются только с полными корректными БЖУ. Значения на 100 мл не подменяются значениями на 100 г. При отсутствии данных остаётся ручная этикетка. Отправляются только названия из текущего поиска, без дневников и других данных localStorage. Ключ perek.us остаётся в существующем серверном окружении. Запросы к модели не выполняются; условия используемых внешних сервисов сохраняются.

Сервер имеет ограниченные фиксированные upstream-адреса, тайм-ауты и кэш запросов. На клиенте есть кэш, задержка ввода продуктов, отмена устаревших запросов и проверка доменов ссылок. При отключении внешнего источника локальные функции сохраняются. Произвольный поиск по всем сайтам интернета не реализован: используются только подключённые публичные базы.
