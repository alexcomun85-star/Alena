# Сайт alenafit.com

Сайт Алёны «Сила без перегибов». Обычные файлы HTML, без сборки, хостинг — GitHub Pages.

- `index.html` — вся страница.
- `img/` — фото, карточки и картинка для превью ссылки (`og.jpg`).
- `CNAME` — подключение домена alenafit.com. Не удалять.

Как обновить: написать Claude в проекте, что поменять. Он внесёт правку сюда, сайт обновится через 1–2 минуты.
