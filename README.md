# Сайт alenafit.com

Сайт Алёны «Сила без перегибов». Обычные файлы HTML, без сборки, хостинг — GitHub Pages.

- `index.html` — главная страница.
- `nauka.html` — «Наука простым языком», 7 разборов исследований.
- `testy.html` — 5 тестов.
- `css/site.css` — оформление всех страниц.
- `img/` — фото, карточки и картинка для превью ссылки (`og.jpg`).
- `CNAME` — подключение домена alenafit.com. Не удалять.

Как обновить: написать Claude в проекте, что поменять. Он внесёт правку сюда, сайт обновится через 1–2 минуты.

## Анонимная форма «Спросить» (vopros.html)

Пока формы нет, на странице стоит заглушка «Сервис в разработке».
Чтобы подключить:
1. Алёна создаёт форму на forms.yandex.ru в своём Яндекс-аккаунте (ответы приходят ей).
2. Поля:
   - «О чём рассказать или что спросить?» — длинный текст, обязательное.
   - «Тема» — один вариант: Тренировки / Техника / Питание / Восстановление / Другое.
   - Подсказка под формой: «Не указывайте имя, контакты, диагнозы и медицинские подробности».
   - Полей для имени, телефона, почты и загрузки файлов НЕ добавлять — форма анонимная, согласие на ПДн не требуется.
3. Ссылку вида https://forms.yandex.ru/u/XXXXXXXX/ вставить в атрибут data-form у #askBox в vopros.html.

Ответы: пост в канале @alena_gymmom с тегом #вопрос или #разбор → через сутки сам появится на vopros.html (data/answers.json).

## Меню
Меню собирается из одного списка в `scripts/build_nav.py` (5 групп: Об Алёне, Тренировки, Питание, Знания и инструменты, Занятия и запись).
Чтобы добавить или переименовать пункт — правка в MENU и запуск `python scripts/build_nav.py` из корня: шапка обновится на всех страницах.

Учёт цикла (27.10.2026, по желанию пользователя, по умолчанию выключен): общий модуль js/cycle.js — настройки в localStorage cycle_settings_v1 (вкл., тип: регулярный / нерегулярный / гормональная контрацепция, длина 21–45, дни месячных 2–10) и дата начала cycle_start_v1 (общая с дневником). Панель настроек одна и та же на страницах progress (#tsikl), servisy (#dnevnik), vozvrat, kalorii. Принцип: фаза цикла сама по себе план не меняет (McNulty 2020, Colenso-Semple 2023) — план меняется только по самочувствию, цикл даёт подсказки и личную картину.
- Журнал (progress): необязательные поля cd (день цикла 1–60, подставляется сам) и fe (как прошла тренировка 1–3) в силовых, cd в замерах; импорт проверяет их. Блок «Цикл и результаты»: подход сравнивается с медианой упражнения за ±21 день, выводы — от 12 записей за 2 цикла, порог ±3 %. Вес — сравнение с тем же днём прошлого цикла. В PDF данные цикла — только по галочке.
- Тренировка дня: «Самочувствие сегодня» (обычно / мало сил / болит живот или поясница) → облегчённый вариант; при боли кор заменён на «кошку-корову», совет к гинекологу. Подсказка по дню цикла при включённом учёте.
- План возвращения: совет про тяжёлые дни цикла; при регулярном цикле — прогноз месячных на 4 недели.
- Калории: подсказка по выбранной дате; цифры и нормы не меняются (разница 3–5 % меньше погрешности подсчёта). golod.html#pered-mesyachnymi, nauka.html#tsikl-eda (Tucker et al., Nutrition Reviews 2025; Hurtová et al., Front Physiol 2026; Benton et al., PLoS One 2020).
- Красные флаги (к гинекологу) — в панели настроек. Тесты: t_cycle в tests/regression.py (168 проверок базового набора).
Ждёт от Алёны: согласовать формулировки облегчённого варианта, красных флагов и блока «Перед месячными». Право: дата цикла — сведения о здоровье (ст. 10 152-ФЗ); пока хранится только в браузере и не передаётся. Если появится в анкете сопровождения — нужно отдельное письменное согласие (перепроверить у юриста).

Карточки техники (27.10.2026): 15 карточек из Canva (иллюстрации ИИ, проверяет Алёна) — img/tehnika/<slug>.webp, 720×960. js/tehnika.js сопоставляет названия упражнений генераторов с карточками и добавляет кнопку «Как делать» (окно <dialog>) в «Тренировку дня» (servisy.html) и «План возвращения» (vozvrat; в PDF кнопки не печатаются). Варианты с другой механикой (на одной ноге, сидя, под углом, с колен) — без карточки. Гоблет-присед добавлен (goblet.webp). Новые карточки: PNG → img/tehnika/<slug>.webp и строка в js/tehnika.js. Ссылки на исходники в Canva — в документе проекта claude/exercise_cards.md.

Нижняя навигация на телефоне и планшете (<1024 px, 27.10.2026): шапка — только логотип и не липнет; всё управление в нижней панели (создаёт js/nav.js на всех страницах): «Главная» (на главной — «Наверх», в режиме приложения — «Назад») · «Мой зал» · «СТАРТ» · «Меню». Меню — шторка над панелью, пункты прижаты к низу экрана, закрывается той же кнопкой, Esc или свайпом. Кнопка «Установить приложение» — в меню. На ПК ничего не изменилось. Тесты t_dock.

## Исправления аудита (27.10.2026)

Меню корректно закрывается при переходе между узким и широким экраном; для 720–1023 px добавлена промежуточная ширина контейнера. Увеличены области нажатия кнопок техники/избранного. Ленты больше не раскрывают невыбранную вкладку.

Калькулятор еды проверяет вес до предпросмотра, подтверждает только успешное сохранение и не затирает повреждённое хранилище. Внизу страницы доступны выгрузка, проверяемый импорт, резервная копия и восстановление (в том числе после очистки). Файлы содержат записи пользователя и обрабатываются локально.

Сервис-воркер v9 заранее сохраняет страницы вместе с CSS/JS. При изменении адресов CSS/JS нужно синхронно обновить их в CORE в sw.js и поднять версию кэша.

Перед публикацией GitHub Actions запускает оба набора: `python tests/regression.py` и `python tests/audit_regression.py`. Второй набор сохраняет снимки экранов 320–1200 px в артефакте mobile-and-fold-checks. Физическое устройство и Samsung Internet проверяются отдельно.

Проверки исправлений пройдены в GitHub Actions: 45 проверок логики Node, 168 базовых браузерных и 186 проверок аудита — всего 399. Запуск: https://github.com/alexcomun85-star/Alena/actions/runs/40572340390. Среда — официальный образ Playwright Python 1.64.1; все тесты обязательны перед публикацией из main.
